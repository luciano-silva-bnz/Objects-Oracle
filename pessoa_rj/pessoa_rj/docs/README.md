# Documentacao Pessoa RJ

Esta pasta concentra a documentacao operacional e tecnica do projeto `pessoa_rj`.

## Arquivos principais

- `manual_utilizacao.md`: guia de uso da aplicacao principal e das rotinas auxiliares.
- `dados_tecnicos.md`: visao tecnica da arquitetura, modulos, empacotamento e pontos de manutencao.
- `manual_utilizacao.pdf`: versao PDF legada.
- `dados_tecnicos.pdf`: versao PDF legada.

## Observacoes

- As versoes `.md` sao a referencia mais atual para a interface atual, incluindo a organizacao por menu e a rotina `Extrato planilha FGTS`.
- Os PDFs existentes foram mantidos na pasta por compatibilidade com distribuicoes anteriores.
